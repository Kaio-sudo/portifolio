# Portfólio Pessoal

## Sobre o projeto

Este projeto consiste no desenvolvimento do meu portfólio pessoal, criado com o objetivo de apresentar minha trajetória na área de tecnologia, minhas habilidades, conhecimentos e projetos desenvolvidos ao longo da minha formação.

O portfólio também funciona como uma forma de demonstrar minha evolução como desenvolvedor e compartilhar meus trabalhos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Apresentação pessoal.
- Exibição de habilidades e conhecimentos técnicos.
- Galeria de projetos desenvolvidos.
- Informações de contato e redes profissionais.
- Footer responsivo com navegação, e-mail e links para redes profissionais.
- Animações de entrada e revelação ao rolar a página, respeitando movimento reduzido.

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` no navegador.
